📋 Fitness & Antrenman Takip Sistemi
Bu proje, sporcuların antrenmanlarını, fiziksel gelişimlerini ve günlük aktivitelerini dijital ortamda takip etmelerine olanak tanıyan Python tabanlı bir yönetim sistemidir. Üniversite bitirme projesi veya portfolyo çalışması olarak geliştirilmiştir.

✨ Özellikler
Sporcu Yönetimi: Sporcu bilgilerini (Ad, Soyad, Yaş, Kilo, Boy) kaydetme ve güncelleme.

Antrenman Takibi: Yapılan egzersizleri, set sayılarını ve sürelerini loglama.

Vücut Kitle Endeksi (VKE) Hesaplama: Sporcuların güncel verilerine göre sağlık durumlarını analiz etme.

Veri Yönetimi: Python sınıfları (Class) kullanılarak modüler ve geliştirilebilir bir yapı.

Hızlı Raporlama: Kayıtlı veriler üzerinden sporcu performansını görüntüleme.
🛠 Kullanılan Teknolojiler
Dil: Python 3.x

Mimari: Nesne Yönelimli Programlama (OOP)

Veri Yapıları: Listeler, Sözlükler ve Sınıf Yapıları
Dosya Yapısı
fitness_app.py: Uygulamanın ana giriş noktası ve kullanıcı arayüzü mantığı.

models/: Sporcu, Antrenman ve Takip gibi temel sınıfların bulunduğu klasör.

__pycache__/: Derlenmiş Python dosyaları.
